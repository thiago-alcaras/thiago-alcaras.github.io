# Portfólio de Thiago Alcarás

Site estático em português, publicado em https://thiago-alcaras.github.io/ pelo GitHub Pages. Não depende de build: HTML, CSS e JavaScript nativos.

## Desenvolvimento

Sirva a raiz com um servidor HTTP estático. Mantenha caminhos relativos para compatibilidade com GitHub Pages. Sem JavaScript, todos os projetos continuam disponíveis. Google Fonts tem fallback para fontes locais genéricas.

## Verificação

Confira desktop e mobile, ausência de rolagem horizontal, imagens, âncoras, filtros por mouse/teclado e funcionamento sem JavaScript. Mantenha `prefers-reduced-motion`, textos alternativos e foco visível.
